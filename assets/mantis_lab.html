01 THE FLIGHT LOOP

Camera → YOLO person detection → selected bearing estimator → registered depth and stop gate → conventional autopilot → four simulated motors. Each controller replay is its own recorded flight; its camera trajectory can differ.

02 THE NEURAL COMPONENT

Mantis Neural uses the upstream Flyvis visual network and a frozen readout. It receives an engineered target mask from YOLO. The eight displayed values are recorded neural features. This is not a complete fly motor brain.

03 WHAT THIS TEST ESTABLISHES

The benchmark reuses identical timestamped observations from the stated source flight. It measures capture-time bearing error and missing outputs. Compute cost is reported separately. These are offline simulations with ideal state and depth, not real-aircraft or real-time validation.
